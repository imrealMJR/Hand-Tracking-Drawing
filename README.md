# برنامه رسم با ردیابی دست 🎨🤚

یک برنامه رسم بلادرنگ مبتنی بر حرکات دست که با **MediaPipe** و **OpenCV** ساخته شده است. همه چیز را با حرکات طبیعی دست کنترل کنید - نیازی به ماوس یا کیبورد برای رسم نیست!

## ✨ ویژگی‌ها

### 🖌️ رسم طبیعی
- **فقط انگشت اشاره** → رسم خطوط سفید صاف و ملایم
- اسکن زمانی (EMA) برای خطوط بدون لرزش
- میانگین متحرک برای صاف‌سازی خطوط

### 🤏 کنترل شئ به‌صورت شهودی (حرکت پینچ)
- **نوک انگشت اشاره + میانه به هم میله** → گرفتن اشیاء
- **حرکت دست در حالت پینچ** → جابه‌جایی انتخاب
- **باز کردن انگشت‌ها بیشتر** → بزرگ کردن (Scale Up)
- **نزدیک کردن انگشت‌ها** → کوچک کردن (Scale Down)
- **چرخاندن مچ** → چرخش انتخاب
- **رها کردن پینچ** → رها کردن شئ

### ✊ کنترل نمای
- **مشت کامل (تمام انگشت‌ها خم)** → بازنشانی زوم/پان به پیش‌فرض

### ⌨️ میانبرهای کیبورد
| کلید | عملکرد |
|-----|--------|
| `C` | پاک کردن تمام نقوش |
| `R` | بازنشانی نمای (زوم/پان) |
| `Q` / `ESC` | خروج از برنامه |

### 🎯 بازخورد بصری
- نمایش بلادرنگ فاصله پینچ
- هایلایت شئ انتخاب شده (مستطیل سیان)
- خط تصویری بین نوک‌های انگشت‌ها در حالت پینچ
- نمایش حالت فعال (DRAW / PINCH_TRANSFORM / RESET / IDLE)
- پس‌زمینه نیمه‌شفاف تیره برای دید بهتر

## 🛠️ پشته تکنولوژیکی

- **Python 3.11+**
- **MediaPipe** (تشخیص نقاط مرجع دست)
- **OpenCV** (بینایی ماشین و رابط گرافیکی)
- **NumPy** (محاسبات عددی)

## 🎮 نحوه استفاده

1. **اجرای برنامه** - یک پنجره با تصویر دوربین باز می‌شود
2. **دست خود را به دوربین نشان دهید**
3. **رسم**: فقط انگشت اشاره را باز کنید و حرکت دهید تا رسم کنید
4. **گرفتن/تبدیل**: نوک انگشت اشاره و میانه را به هم ملاقه کنید (پینچ) روی نقشی که کشیده‌اید
   - حرکت دست → جابه‌جایی نقش
   - باز کردن پینچ بیشتر → بزرگ کردن
   - بستن پینچ بیشتر → کوچک کردن
   - چرخاندن مچ → چرخش نقش
5. **بازنشانی نمای**: مشت کامل بگیرید حدود ۱ ثانیه
6. **پاک کردن بوم**: کلید `C` را بزنید
7. **بازنشانی زوم**: کلید `R` را بزنید
8. **خروج**: کلید `Q` یا `ESC` را بزنید

## 🔧 تنظیمات

پارامترها در متد `__init__` کلاس `DrawingApp` قابل تنظیم هستند:

```python
self.pinch_dist_thresh = 0.08      # حساسیت پینچ (کمتر = حساس‌تر)
self.fist_confidence_thresh = 0.04 # حساسیت تشخیص مشت
self.min_point_dist = 3.0          # حداقل فاصله نقاط رسم
self.ema_alpha = 0.25              # ضریب صاف‌سازی (کمتر = صاف‌تر)
```
